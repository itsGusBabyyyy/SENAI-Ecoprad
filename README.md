# SENAI-Ecoprad
Uma solução apresentada para realizar a prevenção e mitigação da erosão e assoreamento do solo. A Ecoprad é uma empresa fictícia criada para um projeto solicitado pelo Senai MG, do cursode técnico em controle ambiental. Esse repositório busca explorar o passo a passo em cada etapa do processo da solução proposta para o problema apresentado.
